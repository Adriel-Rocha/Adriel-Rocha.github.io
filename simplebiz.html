CASE STUDY · BUSINESS SYSTEM

SimpleBiz Manager

A full-stack business management application designed to centralize customer and product operations in a secure, practical workspace.

Live demo ↗ Source code ↗
ROLE Full-stack developer
FRONTEND React · Vite
BACKEND Java · Spring Boot
DATABASE MySQL
DEPLOYMENT Vercel · Railway

01 · THE PROBLEM

Turning disconnected operations into one workspace.

Small businesses often manage customer and product information across spreadsheets, messages and disconnected tools. This project explores a more centralized workflow: authenticated users access one web application to manage operational records through a REST API.

This is a portfolio demonstration based on common real-world business needs. It is not presented as software currently used by a real client.

02 · THE SOLUTION

A focused business management core.

The first release intentionally concentrates on the parts that are useful to demonstrate a real software delivery: access control, business entities, persistence, API integration and a usable dashboard.

01

Authentication

JWT-based authentication with protected application routes.

02

Authorization

Separate ADMIN and USER roles with different operational permissions.

03

Customers

Create, view, edit, delete, sort and paginate customer records.

04

Products

Manage product descriptions, pricing, stock and active status.

05

Dashboard

Quick operational overview with counts, latest records and shortcuts.

06

API Documentation

OpenAPI/Swagger documentation makes the backend easier to inspect and integrate.
